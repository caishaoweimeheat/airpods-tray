# AirPods Tray 0.2.1-beta

本次更新调整托盘图标的状态颜色：

| 状态 | 图标颜色 |
| --- | --- |
| 已连接 | 绿色（#1FA067） |
| 未连接 | 橙色（#FF8C00） |
| 正在连接 | 黄色 |

未选择目标、未找到目标或无法读取状态时也显示橙色，具体原因可查看鼠标悬停文字或右键菜单。状态每 8 秒自动刷新，也可右键选择“刷新状态”。

## 下载与升级

下载附件 **AirPodsTray-0.2.1-beta-win-x64.zip**，完整解压后运行 `AirPods4Tray.exe`。`Source code` 是源码，不是可直接运行的程序。

1. 右键旧版托盘图标，点击“退出”。
2. 将新版解压到原来的程序目录，替换旧版文件，再运行。
3. 从 0.2.0-beta 升级会保留此前选择的耳机。若更换程序目录，请重新勾选“开机启动”。

## 检查范围

新版已在 GitHub Windows 构建环境编译，通过现有 23 项自动检查；运行包的内容、版本号及 SHA-256 已核对。[查看构建结果](https://github.com/caishaoweimeheat/airpods-tray/actions/runs/42472189620)。

构建环境没有可用的蓝牙耳机，这些检查不等于硬件重连实测。此前 Windows 11 + AirPods 4 的设备枚举和已连接状态验证属于 0.2.0-beta；新版尚未在用户桌面上检查实际托盘显示和断开重连，因此继续标为测试版。

支持 64 位 Windows 10/11，需 .NET Framework 4.5 或以上。耳机必须先在 Windows 中配对，且驱动提供音频重连接口；程序不会自动切换默认声音输出。
