# AirPods Tray 0.2.2-beta

按最新要求调整托盘状态颜色：

| 状态 | 图标颜色 |
| --- | --- |
| 已连接 | 绿色（#1FA067） |
| 未连接 | 蓝色（#2B85BE） |
| 正在连接 | 黄色 |

程序“关于”和使用说明已同步更新。未选择目标、未找到设备或无法读取状态时也显示蓝色，可通过悬停文字或右键菜单查看具体原因。

## 升级方法

1. 右键旧版托盘图标，点击“退出”。
2. 下载 **AirPodsTray-0.2.2-beta-win-x64.zip**，解压后替换旧版程序并运行 `AirPods4Tray.exe`。
3. 已保存的耳机选择会保留。若程序更换目录，请重新勾选“开机启动”。

状态每 8 秒自动刷新，也可右键选择“刷新状态”。

## 验证范围

Windows 自动构建及检查记录：[Build Windows app](https://github.com/caishaoweimeheat/airpods-tray/actions/runs/42473102176)。

构建环境没有可用的蓝牙耳机，实际桌面托盘显示和硬件断开重连仍需手动验证，因此继续标记为测试版。适用条件与前版相同：64 位 Windows 10/11、.NET Framework 4.5 或以上、耳机已配对且驱动提供音频重连接口。
