# AirPods Tray 0.2.0-beta

Windows 右下角托盘中的蓝牙耳机连接工具。首次选择已配对的耳机，之后点击图标即可请求连接。

**这是公开测试版。已在 Windows 11 + AirPods 4 上验证设备识别、选择保存及已连接状态处理；尚未主动断开耳机进行硬件重连测试，其他耳机型号和 Windows 10 也未实测。**

## 下载哪个文件

- **普通用户：下载下方 Assets 中的 `AirPodsTray-0.2.0-beta-win-x64.zip`。** 无需自行编译。
- `SHA256SUMS.txt`：运行包的 SHA-256 校验值。
- `Source code (zip/tar.gz)`：源码快照，供开发者查看、修改或编译。

## 开始使用

1. 在 Windows 蓝牙设置中先配对耳机，并开启蓝牙。
2. 如旧版仍在运行，先右键旧版托盘图标选择“退出”。
3. 将运行包完整解压到准备长期保留的文件夹，双击 `AirPods4Tray.exe`。
4. 在弹出的窗口中选择耳机，点击“设为目标耳机”。
5. 左键点击右下角耳机图标连接。图标藏在 `^` 中时，可将其拖到时钟旁。

蓝色表示未连接，黄色表示连接中，绿色表示播放端点已连接。右键可更换耳机、设置开机启动、打开声音设置或退出。

## 本版功能

- 选择并记住目标耳机，重启程序后恢复选择。
- 区分同名耳机，设备改名后仍能按设备标识匹配。
- 目标缺失时提示重新选择，避免误连其他设备。
- 已连接时点击只提示状态，不重复发送连接请求。
- 高 DPI 设备选择窗口、单实例运行、连接通知和本地日志。

## 运行条件与限制

- 面向 Windows 10/11 x64，需要 .NET Framework 4.5 或以上；实测为 Windows 11 / .NET Framework 4.8。
- 仅支持驱动提供 Windows 蓝牙音频重连接口的已配对播放设备，部分驱动或 LE Audio 专用设备可能不显示。
- 不自动切换默认声音输出。连接后没声音时，右键打开声音设置，选择耳机作为输出。
- 耳机在盒内、没电、超出范围或正被手机占用时，连接可能失败。
- 运行包未进行代码签名。请从本仓库下载；如遇系统拦截，先核对来源与校验值，无需关闭系统防护。

## 升级、卸载与反馈

升级时先退出旧版，再运行新版；移动程序目录后，重新勾选“开机启动”。卸载时取消开机启动、退出程序并删除程序文件夹。

配置与日志在 `%LOCALAPPDATA%\AirPodsTray\`。反馈请使用 [Issues](https://github.com/caishaoweimeheat/airpods-tray/issues)，提供 Windows 版本、耳机型号、操作步骤及错误码；上传日志前删除个人设备标识。
